# 阅读规则与文档归属

## 定位

本集合保存腾讯云 CAM 的来源证据、概念关系、API 契约研究与设计分析。它是外部参考知识，不是 Matrix 已批准需求、当前实现状态或验收记录。研究范围以腾讯云中国站 CAM 文档为主，角色会话补充引用 STS 文档；公开页面不等于内部实现说明。

本集合对应的正式产品与实现归属为 [FEAT-006](../../features/FEAT-006-platform-authorities.md) 和 [FEAT-007](../../features/FEAT-007-control-plane-console.md)。研究建议采纳后应写入相应 FEAT；涉及共同且难以逆转的边界时再由相应 ADR 承接。此处不复制正式需求状态、验收记录或代码清单。

## 按需阅读

先读 [入口索引](README.md)，选中当前问题对应的一篇叶子文档；仅在该文档明确指出缺少前置概念时，再打开相邻主题。不要默认遍历本目录，不要把全部来源或 API 文档装入一次上下文。

普通 UI 修改：先读所属 FEAT，再读相关 UX 主题及其直接引用的概念。权限算法修改：先读所属 FEAT、评估主题及限制说明，再打开相关操作的官方文档。接入 API：先读契约主题，再核对具体接口；目录级阅读不能代替参数验证。

来源核查时才打开 [阅读覆盖与来源](evidence/reading-map.md)。处理冲突时打开 [证据限制](evidence/caveats.md)。会话中断后，从索引重新定位主题；不依赖聊天全文，也不要把这套外部知识当作工作进度检查点。

## 证据等级

**官方事实**表示对应官方文档明确写出的行为，带来源。**界面观察**仅限实际看到的页面、未提交表单及交互，不能证明云端保存或授权成功。**分析**是由公开行为推导的结构关系，不是腾讯内部数据库、网络拓扑或代码实现。**Matrix 建议**是待决定事项，不宣称已经实现。

来源有日期与版本差异时保留适用范围。不能把“来源于官方”当作“所有页面始终一致”。有冲突的结论链接到限制说明，不自行补全缺失契约。

## 单一归属与维护

身份关系归 identities；策略结构和资源标识归 policies-and-resources；请求决策与 ABAC 归 evaluation-and-abac；联合身份和凭证归 federation-and-credentials；管理 API 行为归 contracts；交互分析归 access-management；未采纳的 Matrix 建议归 design-reference；来源元数据与阅读范围归 reading-map。

索引只提供链接和问题入口，不重复正文。新增事实先更新现有主题，不为每次阅读、每个 API 或每一轮讨论创建新文件。只有主题已形成独立边界且当前文件难以按需加载时才拆分。

修改时替换过时结论，保留来源时间和必要的不确定性，不追加逐轮日志。未读内容不能标记已读，阅读不等于运行验证。腾讯二维码、付费、启用、密钥发行和安全配置等流程的限制与正式边界以 FEAT-007 为准；本集合不授权这些操作。
