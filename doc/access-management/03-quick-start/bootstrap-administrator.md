# 建立管理身份

首次使用访问管理时，应先把账号所有权与日常管理分开。账号根身份用于所有权确认、安全恢复和极少数不可委派操作；日常用户、角色、策略和凭据管理由独立管理员身份完成。

## 前提

- 已完成账号所有者的强认证与恢复信息配置。
- 已启用至少一种 MFA，并安全保存恢复材料。
- 已定义日常管理员的职责范围和应急恢复流程。
- 已确定审计事件的接收与告警责任人。

## 建立管理员

1. 使用账号所有者身份进入访问管理控制面。
2. 创建一个对应真实人员的独立用户，不共享用户名或密码。
3. 要求用户在首次登录时设置自己的认证因子。
4. 为用户绑定预置管理策略，或将其加入管理员组。
5. 启用登录 MFA 和敏感操作 step-up。
6. 使用该管理员完成一次登录、只读查询和受保护管理操作。
7. 检查认证、授权和管理变更是否出现在审计记录中。
8. 退出账号所有者会话，并将恢复凭据按离线程序保护。

从账号所有者创建具有管理权限的独立用户，是根所有者与日常管理员分离的第一步。[^1]

## 管理员策略

全局管理员适合初始配置，但常态化运营应继续拆分身份管理员、安全管理员、策略管理员和审计只读角色。若允许委派管理员创建用户和策略，应使用权限边界限制其能够授予的最大权限。

## 验证清单

- 管理员能查看账号摘要、用户、组、角色和策略。
- 管理员可以创建一个无权限测试用户。
- 测试用户默认不能访问业务资源。
- 管理员高风险操作要求 MFA 或 step-up。
- 禁用管理员后，其新登录和新令牌申请立即失败。
- 账号所有者仍可按恢复程序重新建立管理身份。
