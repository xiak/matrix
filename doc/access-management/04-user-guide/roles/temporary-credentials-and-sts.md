# 临时凭据与安全令牌服务

安全令牌服务（STS）把长期主体、外部断言或工作负载证明兑换为短期会话凭据。临时凭据降低秘密长期泄露的影响范围，并为每次委派保留明确会话边界。

## AssumeRole 输入

- 目标角色 ID。
- 调用者的已认证主体。
- 会话名称与稳定 `source_identity`。
- 请求的会话时长。
- 可选会话策略，用于进一步收窄角色权限。
- 可选会话标签。
- 跨账号或第三方集成的外部 ID、受众或资源证明。
- MFA/step-up 证据。

## 校验顺序

1. 验证调用者凭据和主体状态。
2. 验证调用者拥有承担目标角色的权限。
3. 验证目标角色信任策略允许该主体和上下文。
4. 验证 MFA、来源网络、受众、外部 ID 和会话标签。
5. 计算允许的会话时长与会话策略边界。
6. 发行临时 Key ID、Secret、Session Token 和绝对过期时间。
7. 写入角色承担审计事件。

## 会话权限

```text
角色会话有效权限
  = 角色权限策略允许
  ∩ 会话策略允许
  ∩ 角色权限边界
  ∩ 组织权限护栏
  − 任意适用的明确拒绝
```

会话策略和会话标签都不能扩大角色原有权限。请求时长超过角色、账号或组织上限时，STS 应明确拒绝或按公开规则截断，并把实际过期时间返回给调用者。

## 凭据格式与验证

临时凭据必须携带 Session Token，缺少或错配时验证失败。令牌包含或引用角色、会话、账号、发行时间、过期时间、认证强度和撤销版本。签名密钥定期轮换，验证方按 key ID 获取有效公钥。

角色承担与 OIDC 联合均通过 STS 产生临时访问凭证，而不是向角色绑定长期密钥。[^1][^2]

## 撤销

- 到期无条件失效。
- 角色禁用或删除阻止新会话。
- 主体禁用、IdP 禁用或确认泄露可撤销相关会话。
- 明确拒绝和组织护栏在每次业务授权时重新求值，不因旧会话继续允许。
- 验证端缓存撤销版本，并有明确最大陈旧时间。

## 审计

每个会话记录角色 ID、会话 ID、直接承担者、最初主体、外部身份、IdP、来源网络、会话标签和信任策略修订。业务操作同时记录角色主体与原始承担者，使角色共享能力不会破坏责任追踪。
