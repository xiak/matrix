# 单点登录与身份联合

身份联合允许企业身份提供商（IdP）完成用户认证，访问管理作为服务提供方（SP）验证断言、映射身份并建立本地用户会话或角色会话。产品支持 SAML 2.0 与 OpenID Connect（OIDC）两类协议。

## 联合模式

| 模式 | 本地对象 | 会话形态 | 典型用途 |
| --- | --- | --- | --- |
| 用户 SSO | 稳定本地用户 | 用户会话 | 员工长期使用控制台，需要本地用户生命周期 |
| 角色 SSO | 角色与外部主体映射 | STS 角色会话 | 临时访问、跨账号、合作人员、工作负载 |

产品区分用户 SSO 与角色 SSO，并分别支持 SAML/OIDC 配置。[^1]

## IdentityProvider 模型

- 所属账号与稳定 IdP ID。
- 协议、发行者、允许受众/客户端。
- SAML 元数据或 OIDC discovery/JWKS 地址。
- 签名与加密算法白名单。
- 外部主体、用户、组、角色和会话标签映射。
- 回调地址、登录入口和启用状态。
- 配置修订、证书或密钥轮换状态。

## 用户 SSO

1. 用户从账号登录入口或 IdP 发起登录。
2. IdP 认证用户并签发断言。
3. SP 校验签名、发行者、受众、时间、nonce/断言 ID 和回调。
4. 使用稳定外部主体 ID 映射本地用户。
5. 校验用户状态与账号登录策略。
6. 建立用户会话并记录 IdP 与外部身份。

映射不能只依赖邮箱或显示名。若允许即时预配，创建规则、默认组、属性白名单和离职处置必须显式配置。

## 角色 SSO

1. IdP 断言给出外部主体和允许的角色候选。
2. 用户选择目标账号和角色，或由应用固定目标角色。
3. STS 同时校验 IdP 配置、角色信任策略、受众和会话属性。
4. 发行有时限角色凭据或控制台登录令牌。
5. 审计记录外部主体、IdP、角色、会话和原始断言 ID 摘要。

OIDC 工作负载联合必须将受众、主体模式和环境声明绑定到具体信任，防止来自其他仓库、集群或流水线的令牌被接受。

## 协议安全

- 禁止未签名断言和不受信算法。
- 严格比较 issuer、audience、client ID 与回调地址。
- 校验 `not_before`、`expires_at`，并限制时钟偏差。
- SAML assertion ID、OIDC nonce 和授权码均防重放。
- JWKS/证书更新验证来源并支持有界双密钥轮换。
- 禁用 IdP 后阻止新会话，并按安全策略撤销现有会话。
- 错误响应不回显完整断言、令牌或敏感属性。

## IdP 生命周期

创建配置时先验证元数据、域名所有权和测试登录；正式启用前保留根恢复入口。更新配置使用新修订和测试会话，避免一次错误 IdP 配置锁死账号。删除前列出依赖的用户映射、角色信任和活跃会话。
