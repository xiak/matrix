# 安全分析报告

安全分析报告把身份、凭据、策略、角色和授权审计投影为可执行的安全发现。报告用于发现风险和验证整改，不参与在线授权求值。

## 报告范围

### 身份发现

- 根身份缺少 MFA 或存在永久访问密钥。
- 管理员未启用 MFA。
- 长期未登录或已离职但仍活跃的用户。
- 多个用户共享可疑登录来源或凭据。
- 外部身份映射冲突、IdP 即将过期证书。

### 凭据发现

- 长期未轮换的访问密钥。
- 从未使用或长期未使用的密钥。
- 密钥缺少网络来源限制。
- 同一密钥跨多个不相关产品或地域使用。
- 已禁用主体仍存在活动会话或密钥。

### 权限发现

- 对所有资源开放敏感写动作。
- 未使用的策略、策略绑定或角色。
- 用户直接绑定过多例外策略。
- 权限边界缺失或可被自身移除。
- PassRole、角色信任或跨账号策略范围过宽。
- ABAC 标签可由被授权主体自行修改。

### 使用发现

- 用户、密钥和角色最近使用时间。
- 策略允许动作与实际使用动作的差异。
- 高频拒绝、异常地域、异常时间和高风险操作。
- 授权决定与业务执行结果无法关联的审计缺口。

安全分析报告以密钥活跃时间、闲置用户、角色承担与操作审计等数据作为输入。[^1]

## 数据语义

报告标明采集时间、水位、统计窗口和覆盖产品。异步审计未到达时不能把“未观察到使用”表述为“从未使用”。每条发现包含对象、证据、风险、建议动作、首次/最近观察时间和状态。

## 处置流程

1. 安全人员确认数据完整性与对象所有者。
2. 使用有效权限和最近使用记录评估影响。
3. 对拟议策略收紧、密钥禁用或角色删除进行模拟。
4. 由对应管理 API 执行变更，报告系统不直接越权修改。
5. 观察拒绝和业务错误，必要时回滚策略版本。
6. 关闭发现并保留证据与处置审计。

## 导出与访问控制

报告包含敏感主体、策略和网络信息。在线查看、生成、下载和分享分别授权；导出文件加密、设定有效期并写审计。跨账号集中报告只展示被明确委派的账号范围。
