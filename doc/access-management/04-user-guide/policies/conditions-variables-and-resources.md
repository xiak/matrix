# 条件、变量与资源表达

## 规范资源名

资源名在所有产品间提供统一定位语法，同时保留产品特有层级。一个规范资源名至少表达：服务、地域、资源所属账号、资源类型和资源路径。

```text
crn:{service}:{region}:{account}:{resource-type}/{resource-path}
```

示例：

```text
crn:storage:region-a:account-123:bucket/example/object/reports/2026.pdf
```

规范资源名使用分段结构，并允许不同产品定义自己的资源部分。[^1] 资源标识必须可解析、可比较、可被产品验证，并且账号与地域语义明确。

## 动作表达

动作采用产品命名空间与操作名，例如 `database.instance.read`、`database.instance.modify`。产品可以提供服务级、动作级或资源级授权；不支持资源级的动作只能使用产品声明的服务资源范围。

## 策略变量

策略变量在求值时从可信上下文取值，用于减少重复规则。例如资源路径包含当前用户 ID，或资源标签必须等于主体部门。变量必须声明类型和缺失行为，不能把未定义值替换为空字符串。

## 条件键来源

| 命名空间 | 示例 | 所有者 |
| --- | --- | --- |
| request | 来源 IP、时间、客户端、请求标签 | 网关或产品请求解析器 |
| principal | 主体 ID、账号、类型、属性、标签 | 身份服务 |
| session | 角色、认证强度、会话标签、发行时间 | 认证服务或 STS |
| resource | 所属账号、地域、类型、标签、父资源 | 业务产品 |
| environment | 网络区域、设备风险、组织路径 | 受信平台服务 |

全局条件包含请求时间、来源 IP、资源标签与请求标签等，并按数据类型提供不同操作符。[^2]

## 操作符

- 字符串：等于、不等于、前缀、受控模式匹配。
- 数值：等于、大小比较、范围。
- 布尔：真/假。
- 日期时间：之前、之后、范围。
- IP：属于/不属于 CIDR。
- 集合：任一、全部、包含、不包含。
- ARN/资源名：等于、模式匹配。
- 空值：键是否存在。
- 引用比较：一个可信属性与另一个可信属性比较。

操作符只接受匹配类型；时间、IP 和布尔值在发布时规范化。集合修饰符必须说明是 `any` 还是 `all`。

## 属性安全

- 授权属性有唯一所有者和写入权限。
- 资源创建前使用请求标签求值，防止先创建无标签资源。
- 修改决定自身权限的主体或资源标签是独立敏感动作。
- 父子资源标签不自动继承，除非产品明确声明继承规则。
- 审计记录使用的键和必要摘要，敏感值按权限脱敏。
