# 访问管理词汇表

| 术语 | 定义 |
| --- | --- |
| 账号（Account） | 资源所有权、策略管理与治理隔离的顶层边界。 |
| 根身份（Root Identity） | 账号创建时产生的所有者与恢复身份，不用于日常操作。 |
| 主体（Principal） | 能被认证或被策略引用的用户、服务、账号、角色会话或外部身份。 |
| 用户（User） | 具有稳定生命周期的人员或兼容性服务身份。 |
| 外部协作者 | 来自另一个账号或组织、在本账号获得受控访问的主体。 |
| 通知联系人 | 只接收消息的联系对象，不是可授权主体。 |
| 用户组（Group） | 用于批量绑定策略的用户集合。 |
| 凭据（Credential） | 证明主体身份的密码、MFA、访问密钥、令牌或外部断言。 |
| 访问密钥（Access Key） | 由公开 Key ID 与保密 Secret 组成的 API 签名凭据。 |
| 会话（Session） | 一次有时限的认证结果，包含主体、认证强度和上下文。 |
| MFA | 使用两个或更多独立因子验证身份。 |
| Step-up | 在现有会话中为敏感操作重新完成更强认证。 |
| 角色（Role） | 无永久凭据、可由可信主体临时承担的虚拟身份。 |
| 信任策略（Trust Policy） | 定义哪些主体在什么条件下可以承担角色。 |
| 角色会话（Role Session） | 一次成功承担角色后产生的短期身份。 |
| STS | 验证角色或联合信任并发行短期凭据的安全令牌服务。 |
| 服务角色 | 允许已注册业务服务代表账号访问其他产品的角色。 |
| 服务关联角色 | 生命周期与特定产品能力绑定、信任与权限模板受控的角色。 |
| 资源角色 | 与实例、容器、函数等业务资源绑定的工作负载角色。 |
| PassRole | 把指定角色交给指定服务使用的独立授权动作。 |
| 身份提供商（IdP） | 通过 SAML 或 OIDC 认证外部主体并签发断言的系统。 |
| 用户 SSO | 外部身份映射为稳定本地用户并建立用户会话。 |
| 角色 SSO | 外部身份映射为角色并建立短期角色会话。 |
| 策略（Policy） | 包含一个或多个授权 statement 的版本容器。 |
| Statement | 使用 effect、action、resource、condition 和可选 principal 表达的一条规则。 |
| 身份策略 | 绑定用户、组或角色，定义主体候选权限的策略。 |
| 资源策略 | 绑定业务资源，定义哪些主体可访问该资源的策略。 |
| 明确拒绝（Explicit Deny） | 匹配时优先于任何允许的拒绝规则。 |
| 默认拒绝（Default Deny） | 没有适用允许时自动拒绝请求。 |
| 权限边界 | 绑定用户或角色、只能收窄权限的最大权限策略。 |
| 组织护栏 | 在组织或账号层级限制最大权限的治理策略。 |
| 动作（Action） | 业务产品发布的稳定可授权操作。 |
| 资源（Resource） | 业务产品拥有、可被动作作用并由规范名称标识的对象。 |
| 条件（Condition） | 基于可信属性决定 statement 是否匹配的表达式。 |
| ABAC | 根据主体、会话、资源、请求和环境属性实施访问控制。 |
| 规范资源名（CRN） | 跨产品唯一表达服务、地域、账号、类型与资源路径的名称。 |
| Authorization Profile | 业务产品发布的动作、资源、条件、标签和角色能力契约。 |
| PEP | 在网关或业务产品中执行授权结果的策略执行点。 |
| PDP | 收集策略并输出允许或拒绝的策略决定点。 |
| PIP | 向求值提供可信主体、资源与环境属性的策略信息点。 |
| PAP | 管理身份、策略、角色和配置的策略管理点。 |
| 授权决定 | 对具体主体、动作、资源和上下文的一次不可变允许/拒绝证据。 |
| 原始主体 | 角色、服务或联合会话背后最初发起操作的人员或工作负载。 |
| 策略版本 | 发布后不可修改、可被设为默认或用于回滚的策略内容修订。 |
| 策略分析器 | 在发布前校验结构、产品语义和权限风险的组件。 |
